# Feature: MVP Validation

## Goal

Validar el MVP en un gimnasio real con coaches y boxeadores reales.

## Users

- admin
- coach
- boxer
- product team

## Scope

- carga de datos reales
- pruebas reales de entrenamiento
- feedback funcional
- validación de UX
- medición de uso

## Metrics

- active coaches
- active boxers
- exercises started
- exercises completed
- attendance records
- progress entries created
- weekly usage frequency
- retention

## Validation Goals

- el coach usa el flujo mobile real
- el boxer carga progreso
- el historial es útil
- la app aporta valor operativo

## Acceptance Criteria

- al menos un gimnasio usa el MVP
- existen ejercicios reales registrados
- existe feedback accionable
- se identifican mejoras claras para v2
