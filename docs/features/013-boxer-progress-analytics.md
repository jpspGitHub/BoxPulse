# Feature: Boxer Progress Analytics

## Goal

Mostrar análisis simple entre actividad física y progreso del boxeador.

## Users

- boxer
- coach

## Scope

- gráficos básicos
- métricas resumidas
- relación visual simple entre actividad y progreso

## Analytics Examples

- entrenamientos por semana
- evolución de peso
- asistencia mensual
- frecuencia de ejercicios
- actividad comparada con progreso físico

## Business Rules

- evitar métricas complejas en MVP
- priorizar claridad visual
- el análisis debe entenderse rápidamente

## Acceptance Criteria

- existen gráficos básicos
- la evolución física es visible
- la relación actividad/progreso es visible
