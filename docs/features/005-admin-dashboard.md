# Feature: Admin Dashboard

## Goal

Dar visibilidad básica de la operación del gimnasio.

## Users

- admin

## Scope

- métricas generales
- actividad reciente
- resumen operativo

## KPIs

- total users
- total coaches
- total boxers
- active exercises
- completed exercises
- attendance overview

## Business Rules

- el dashboard debe cargar rápido
- mostrar datos reales
- navegación rápida hacia gestión

## Acceptance Criteria

- el admin puede visualizar métricas básicas
- existe resumen de actividad reciente
- la navegación hacia usuarios funciona
