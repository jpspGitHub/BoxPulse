# Feature: Coach Boxer Tracking

## Goal

Permitir que el coach haga seguimiento de boxeadores desde mobile.

## Users

- coach

## Scope

- ver boxeadores
- ver progreso físico
- ver asistencia
- ver ejercicios realizados
- registrar observaciones

## Business Rules

- el coach solo ve boxeadores del gimnasio
- el coach puede consultar historial
- las observaciones quedan historizadas

## Acceptance Criteria

- el coach puede abrir detalle del boxer
- el progreso es visible
- la asistencia es visible
- el historial de ejercicios es visible
