# Feature: Boxer Profile Management

## Goal

Permitir que el boxeador gestione su información personal.

## Users

- boxer

## Scope

- editar perfil
- actualizar teléfono
- actualizar avatar
- cambiar contraseña

## Business Rules

- el boxer solo puede editar sus datos
- el avatar debe persistirse correctamente
- el cambio de contraseña requiere validación

## Acceptance Criteria

- el boxer puede editar perfil
- el boxer puede actualizar imagen
- el boxer puede cambiar contraseña
